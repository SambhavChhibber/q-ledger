Q-LEDGER

Q-LEDGER is a cutting-edge personal finance management application featuring a stunning glassmorphism UI inspired by Apple's visionOS design. The app includes a secure authentication system with login/signup functionality and session management. Users can effortlessly track their finances by adding income (INFLOW) and expense (OUTFLOW) transactions with detailed descriptions, custom amounts in Indian Rupees (₹), and selectable dates. The intelligent auto-categorization system uses keyword matching to automatically classify transactions into categories like Income, Housing, Shopping, Travel, Food & Dining, and Miscellaneous, with real-time category prediction as you type. The budget management module allows users to set monthly spending limits and provides automatic alerts when expenses exceed the defined hard limit, displaying compliance status in a dedicated Security Module Analysis panel. Users can create and track multiple savings goals with visual progress rings showing percentage completion, and easily allocate funds (₹1k or ₹5k increments) toward their targets. The app features a comprehensive dashboard displaying three key metrics: Net Account Balance, Monthly Inflow, and Monthly Outflow, all calculated in real-time. Quick Deployment Templates enable rapid transaction logging with pre-configured templates for common expenses. The transaction ledger displays all entries with color-coded tags, dates, categories, and amounts, with smooth hover animations and the ability to delete entries via confirmation modals. Advanced UI features include interactive glassmorphism effects with backdrop blur, smooth micro-interactions on all buttons, hover animations with shimmer effects on transaction rows, clickable stat cards and transactions that activate a beautiful blurred background overlay, and responsive design that adapts seamlessly to different screen sizes. All data is persisted locally using the browser's localStorage API, ensuring your financial information remains private and accessible across sessions. Additional features include JSON export functionality for backup and external analysis, a full-screen scrollable interface with smooth snap scrolling between sections, and console logging for debugging and tracking user actions. The entire application is built with vanilla JavaScript, CSS3, and HTML5—no external frameworks required—making it lightweight, fast, and easy to customize.
